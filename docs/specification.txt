Objetivo
Criar Shopping Lists no Auctionator a partir dos requisitos dos Caixotes Extraviados do WoW Forever, lidos dinamicamente do tooltip. Não usar catálogo fixo de caixotes ou materiais.

Ambiente já investigado
- Instalação: C:\Program Files (x86)\World of Warcraft\_forever_
- Addons: Interface\AddOns dentro dessa instalação.
- Cliente identificado: 1.60.1.70938.
- Interface indicada pelos addons instalados: 16001.
- Auctionator instalado: versão 346.
- Confirme esses dados antes de implementar.
- Verifique se C:\Repos\CrateShop já existe e preserve arquivos existentes.
- Não modifique Economy Companion, PocketGold ou outros repositórios.
- Use Lua, TOC e XML somente se necessário. Sem dependências externas de execução.
- Inicialize Git localmente se necessário, com branch codex/initial-addon.
- Não faça push, crie remoto ou publique no GitHub.
- Entregue a pasta CrateShop pronta para copiar para AddOns. Não instale no jogo automaticamente.

Validação já realizada dentro do Forever
O usuário confirmou que:
1. GameTooltip:GetItem() retorna o hyperlink do caixote.
2. As linhas visíveis podem ser lidas por Lua.
3. C_TooltipInfo.GetHyperlink(hyperlink) retorna os requisitos completos em data.lines[i].leftText.
4. Todo o bloco de requisitos fica em uma única linha lógica do tooltip, com quebras de linha internas.
5. A consulta pelo hyperlink retornou o tooltip sem os complementos adicionados por outros addons.

Fluxo esperado
1. Com Auction House aberta, observar Shift+clique em um item por hook seguro.
2. Obter hyperlink e Item ID.
3. Consultar C_TooltipInfo.GetHyperlink.
4. Reconhecer a estrutura de preenchimento do caixote.
5. Interpretar todas as alternativas.
6. Exibir confirmação com nome do caixote, número de alternativas e botões Criar lista/Cancelar.
7. Deixar explícito que os materiais são alternativas: basta escolher um conjunto.
8. Somente após confirmação, gravar a lista no Auctionator.
9. Mostrar mensagem breve de sucesso.

Detecção
O Auctionator instalado usa hooks seguros em:
- ChatFrameUtil.InsertLink, quando disponível;
- ChatEdit_InsertLink, como alternativa.

Inspecione Source\Shopping\Hooks.lua e confirme a integração adequada.
Filtre Auction House aberta, Shift pressionado e hyperlink de item. Evite capturar gestos destinados a escrever links no chat.
Não substitua funções originais nem interfira no funcionamento do Auctionator.
Não suprima a busca que o próprio Auctionator já realiza normalmente com Shift+clique. O CrateShop não deve iniciar buscas adicionais.

Parser
- Mantenha-o isolado e testável sem o cliente.
- Use a frase real “Encha o caixote com qualquer conjunto da lista a seguir:” como marcador estrutural.
- Divida também as quebras de linha internas de cada linha lógica.
- Leia alternativas no formato “- quantidade nome”.
- Preserve nomes localizados e quantidades inteiras positivas.
- Aceite quantidade variável de alternativas, ordem variável e formatação colorida.
- Não dependa exclusivamente do nome ou ID do caixote.
- Não confunda nível, preço, recompensas ou informações de outros addons com requisitos.
- Não aceite silenciosamente um bloco parcialmente interpretado.
- Se o formato for incompleto ou ambíguo, informe o problema e não crie lista.
- Itens comuns devem ser ignorados sem abrir confirmação nem gerar spam.
- Diferencie item comum de caixote reconhecido com requisitos inválidos.
- Não afirme que uma truncagem silenciosa é detectável sem evidência.

Integração com Auctionator
Foram verificadas estas funções na instalação:
- Auctionator.API.v1.ConvertToSearchString(callerID, term)
- Auctionator.API.v1.CreateShoppingList(callerID, name, searchStrings)
- Auctionator.API.v1.GetShoppingListItems(callerID, name)

Exemplo de termo:
{
    searchString = "Minérios de Mithril",
    isExact = true,
    quantity = 20
}

O WhatsItFor instalado e o projeto RestockShoppingList utilizam ConvertToSearchString e CreateShoppingList.

Ressalva importante:
Na versão 346 instalada, CreateShoppingList substitui listas de mesmo nome e dispara ListImportFinished. Isso expande a lista e pode iniciar pesquisa conforme AUTO_LIST_SEARCH.

Preserve o requisito de não iniciar pesquisas adicionais:
- Prefira API pública quando atender ao comportamento exigido.
- Se necessário, use um adaptador pequeno para as funções verificadas do gerenciador de listas.
- Inspecione Source\Shopping\Mixins\ListManager.lua, List.lua e os consumidores dos eventos antes de decidir.
- Não escreva diretamente nas SavedVariables do Auctionator.
- Não substitua temporariamente funções globais, não suprima eventos globalmente e não altere as configurações do jogador para contornar a pesquisa automática.
- Verifique disponibilidade das funções e recuse a operação com mensagem clara se a integração não for compatível.
- Documente qualquer dependência de interfaces internas.
- Não execute compras ou buscas automáticas.
