# Identidade visual do CrateShop

`crateshop-avatar.png` é o avatar original preparado para a página do CurseForge. PNG quadrado com fundo opaco; não é necessário incluí-lo no pacote instalado do addon. O ícone nativo usado no jogo permanece inalterado.

Gerado com a ferramenta integrada ImageGen em 2026-11-17, sem imagens de referência ou assets extraídos do jogo. A licença MIT do projeto acompanha este material.

Direção visual / prompt: avatar quadrado original para CrateShop, caixote de madeira reforçado em bronze ligeiramente aberto, três moedas douradas e pergaminho com checklist; ilustração de fantasia pintada, fundo carvão, detalhes em ouro antigo, silhuetas claras e bom contraste em tamanhos pequenos. Sem texto, marcas, moldura ornamentada ou reprodução de arte existente do jogo.
